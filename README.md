# Triage Collector For Windows
this is a python Script that has been tested using python 3.11 to gather windows digital forensic evidence for Triage. I have not tested it with any other version. This does require to run as an administrator. 
note that the artifacts to collect are defined at the beginning of the script. this is released under the MIT license.
