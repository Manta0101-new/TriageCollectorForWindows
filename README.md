# Triage Collector For Windows
this is a python Script that has been tested using python 3.11 to gather windows digital forensic evidence for Triage. I have not tested it with any other version. This does require to run as an administrator. 
note that the artifacts to collect are defined at the beginning of the script. this is released under the MIT license. 
the files to copy are included in the list. Notice that the entire appdata directory is not being captured but only relevant parts of it related to artifacts. you could change this to include all the appdata direcctory for each user but, personally, I would think it best to focus on relevant artifacts. This script can also be converted into a full disk image process, with some configuration changes(output path). I will leave that up to you.
